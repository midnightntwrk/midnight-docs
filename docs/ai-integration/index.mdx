# AI integration

AI coding assistants are fast, but they hallucinate on Midnight. Compact and the Midnight SDK are barely represented in their training data, so an assistant left on its own invents syntax, calls functions that do not exist, and hands you code that fails at compile time.

This section covers tools that close that gap. They keep you in a human-in-the-loop workflow, where you steer, review, and approve. Meanwhile, the assistant checks its own output against the real Compact compiler, SDK, and source before showing it to you. You stay in control, and the tooling handles the verification. The result is less time debugging invented code and more time building.
