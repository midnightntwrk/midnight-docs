# Midnight Expert

Midnight Expert is a suite of Claude Code plugins for developers building on Midnight. It helps you write and review Compact smart contracts, scaffold and wire up DApp frontends, manage your local toolchain and devnet, and verify claims about your code against the real source, all from inside your editor.

The design goal is to stay out of your way. Once it is installed, you rarely invoke anything by hand. As you describe what you are building, the relevant plugins and skills activate on their own. It is a coding assistant that keeps you in the loop, and its main benefit over a plain assistant is that it verifies its own work, which sharply reduces hallucinated code.

Midnight Expert is built as Claude Code plugins today. Support for more assistants is on the way.

## Prerequisites

- Claude Code (the CLI or an IDE extension).
- macOS or Linux. On Windows, run everything inside [WSL2](https://learn.microsoft.com/windows/wsl/).
- `jq` and the GitHub CLI. The installer checks for these and helps you install any that are missing.

## Install

Pick whichever method fits your workflow. If you are not sure, use the guided installer.

### Guided installer (recommended)

Run this in your terminal and follow the prompts. It registers the marketplace, enables the plugins, and checks that everything it needs is in place.

```bash
curl -fsSL https://midnightntwrk.expert/install.sh | bash
```

### From inside Claude Code

1. Run `/plugin` to open the plugin manager.
2. Choose **Add marketplace** and paste `https://midnightntwrk.expert`.
3. Use **Browse plugins** to enable the plugins you want.

### From the command line

```bash
claude plugin marketplace add https://midnightntwrk.expert
```

:::info[Restart after a mid-session install]
Slash commands from a plugin installed mid-session only appear after you restart Claude Code. Skills and agents activate right away.
:::

## Verify your setup

Run the diagnostics command to confirm your environment is ready:

```text
/midnight-expert:doctor
```

It reports on plugin installation, external tools, and connectivity, and can offer fixes for anything it finds.

## Try it

Most of the time you describe what you want, and the right plugin activates on its own. Here are starting points across the common tasks.

| You want to | Ask your assistant |
| :--- | :--- |
| Write a contract without hallucinated syntax | "Write a Compact contract for a sealed-bid voting system and walk me through the disclosure rules." |
| Scaffold a DApp frontend | "Scaffold a Vite and React DApp wired to my counter contract and connect it to the Lace wallet." |
| Check your local stack | "Is my local proof server healthy, and is the indexer caught up to the node?" |
| Understand a rejected transaction | "My transaction was rejected with code 166. What does that mean?" |
| Fix a privacy error | "I'm getting a potential witness-value disclosure error. What does it mean, and how do I fix it?" |
| Review before you push | "Review `contracts/Report.compact` for potential privacy leaks before I push." |

Because the assistant checks its own output against the real Compact compiler, SDK, and source before showing it to you, you get working code instead of code that only looks right.

If you prefer to invoke a workflow directly, the slash commands are there too:

```text
/midnight-tooling:devnet start
/midnight-status-codes:lookup 166
/midnight-verify:verify "Compact tuples are 0-indexed"
/midnight-expert:doctor
```

## What is inside

Midnight Expert bundles plugins grouped by what you are doing:

- **Smart contract development.** Write, review, and debug Compact, work from compilable examples, and scaffold a contract CLI.
- **DApp development.** Scaffold a React frontend and wire it to your contract and the Lace wallet.
- **Testing and code quality.** Linting, type-checking, and testing for contracts, DApps, and wallet code.
- **Toolchain and infrastructure.** Install the Compact CLI, run a local devnet, work with the proof server, and look up any error code.
- **Knowledge and concepts.** Architecture, privacy patterns, tokenomics, and zero-knowledge proofs, explained on demand.

Every plugin ships a detailed README covering its skills, agents, and commands. Rather than repeat that here, browse them at the source.
