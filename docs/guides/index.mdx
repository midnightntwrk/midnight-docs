## All guides

### Set up your environment

- [Networks and environments](./networks-and-environments.mdx): choose a network, look up its endpoints, run a local network, and prepare for Mainnet.
- [Run the proof server](./run-proof-server.mdx): start the proof server from Docker Desktop, for wallet users rather than DApp builders.
- [Prove transactions locally](./local-proving.mdx): learn why proving runs on your machine, then run a proof server and connect your DApp to it.
- [Windows Compact setup](./windows-compact-setup.mdx): set up WSL, Docker Desktop, the proof server, and the Compact compiler on Windows.
- [Set up Bun for Midnight development](./install-bun-runtime-midnight.mdx): install Bun and the Compact compiler, then compile a contract and use it from a Bun application.

### Fund a wallet and pay fees

- [Fund a wallet](./acquire-tokens.mdx): get tNIGHT from the faucet and register it for DUST generation, in Lace or with the wallet SDK.
- [Manage DUST](./manage-dust.mdx): read DUST balances, estimate a fee, send several transactions from one wallet, and resolve DUST errors.
- [DUST sponsorship](./dust-sponsorship.mdx): pay DUST fees on behalf of your users.

### Test, deploy, and secure a smart contract

- [Build a private smart contract](./build-a-private-smart-contract.mdx): keep data on-device, disclose only what is needed, then compile and test the contract locally.
- [Use Compact contracts from JavaScript](./compact-javascript-runtime.mdx): implement witnesses, call circuits, and write unit tests for a compiled contract.
- [Manage private state with witnesses](./private-state-witnesses.mdx): declare witnesses in Compact, implement them in TypeScript, wire up private state, and avoid common pitfalls.
- [Deploy and operate a contract](./deploy-and-operate.mdx): configure the Midnight.js providers, deploy a contract, observe its state, and keep it updatable.
- [Security and best practices](./security-best-practices.mdx): authenticate callers, validate inputs, enforce deadlines, and prevent replay attacks.

### Connect a wallet to a frontend

- [Create a React wallet connector](./react-wallet-connect.mdx): connect a React application to a Midnight wallet through the DApp Connector API.
- [Create a Next.js wallet connector](./nextjs-wallet-connect.mdx): connect a Next.js application to a Midnight wallet through the DApp Connector API.

### Index contract state and build across chains

- [Index contract state with EffectStream](./index-state-with-effectstream.mdx): watch a Midnight contract and serve its public state over HTTP.
- [Build a cross-chain DApp with EffectStream](./build-cross-chain-dapp-with-effectstream.mdx): run a template whose state lives on Midnight and an EVM chain.
