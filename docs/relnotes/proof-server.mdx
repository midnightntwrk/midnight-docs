# Proof Server

:::info[Proof server releases are now part of Ledger]
Starting with Ledger 7.0.0, proof server releases appear on the [Ledger page](./ledger), not on this page. Images for 7.0.0 and later are on Docker Hub as [`midnightntwrk/proof-server`](https://hub.docker.com/r/midnightntwrk/proof-server). For the version to run on each network, see the [compatibility matrix](./support-matrix).

The releases on this page predate that change. Their images, up to 4.0.0, are in the older `midnightnetwork/proof-server` repository.
:::

Proof Server is a component of the Midnight infrastructure that enables zero-knowledge proof generation, transaction verification, and privacy-preserving transaction processing.

[Link to related documentation](../guides/run-proof-server)

To download the component, click the appropriate link under **Artifacts**.
