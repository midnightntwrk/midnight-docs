<h1 style={{ marginBottom: '0.1rem' }}>Latest stable release</h1>

## Compatibility

Mainnet runs Midnight Ledger 9.1.0.1 after the ledger 9 network upgrade on 6 November 2026. Preview and Preprod run Midnight Ledger 8.1.3 until a later upgrade.

Each network uses its own versions of the runtime, SDKs, and tooling. To learn what changed on Mainnet and what you need to do, see [Ledger 9 upgrade](./ledger-9).
 
---  
  
## Environments  

Midnight uses dedicated network services such as RPC nodes, indexer API, and proof server to power DApp development and interaction across the Preview, Preprod, and Mainnet environments. To connect your application and configure these services correctly, see the [Environments and endpoints](./network) reference.

---  
  
## Compatible components

Building on Midnight requires a set of compatible components to work properly. When creating DApps, use the component versions listed for the network you target.

To view the full list of components and their compatible versions for each network, see the [Compatibility matrix](./support-matrix).
