# Security audits

The Midnight Foundation commissions independent security audits of Midnight components. This page lists the published reports.

Each report appears here exactly as the auditor delivered it. The status of each finding reflects the auditor's verification at the code revision named in the report. Later releases may have changed the code.

To report a security vulnerability, follow the [Midnight Foundation security policy](https://github.com/midnightntwrk/midnight-docs/blob/main/SECURITY.md). Use GitHub private vulnerability reporting, or email [security@midnight.foundation](mailto:security@midnight.foundation). Do not open a public issue.
