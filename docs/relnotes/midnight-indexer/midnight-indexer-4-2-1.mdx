## High-level summary

Midnight Indexer 4.2.1 is a dependency release on the development line. It moves the node dependency to 1.0.0-rc.3 and `midnight-storage-core` to 1.2.0-rc.3, and adds Preprod genesis and multi-transaction apply benchmarks. No schema or behaviour changes for API consumers.

---

## Audience

This release note is relevant for:

- Operators running the Midnight Indexer against Node 1.0.0 release candidates

---

## What changed

- Bumped to Node 1.0.0-rc.3 and `midnight-storage-core` 1.2.0-rc.3 ([#1077](https://github.com/midnightntwrk/midnight-indexer/pull/1077))
- Added Preprod genesis and multi-transaction apply benchmarks ([#1076](https://github.com/midnightntwrk/midnight-indexer/pull/1076))

---

## Breaking changes

None. Drop-in upgrade from 4.2.0.
