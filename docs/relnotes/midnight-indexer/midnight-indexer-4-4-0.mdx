## High-level summary

Midnight Indexer 4.4.0 is the indexer line for the [ledger 9 network upgrade](/relnotes/ledger-9). It indexes the chain across the switch from ledger 8 to ledger 9, so it reads both ledger 8 and ledger 9 blocks.

Mainnet moves to ledger 9 at the upgrade. Preview and Preprod stay on ledger 8 and the 4.3.x indexer line until a later upgrade.

## Audience

This release note is relevant for:

- Operators who run their own Midnight Indexer against Mainnet
- Wallet and DApp developers who query a self-hosted indexer on Mainnet

If you use a hosted Mainnet indexer, you don't need to re-index. Check with your provider that it runs the 4.4.x line.

---

## What changed

- Indexes the ledger 9 network upgrade on Mainnet, reading ledger 8 blocks before the switch and ledger 9 blocks after it.
- Serves post-upgrade state for contracts that no transaction has touched since the switch. This is a breaking change and adds a database migration.
- Reports zero fees for failed transactions.

## Breaking changes

- The 4.4.x line needs a database built by 4.4.x. You can't upgrade an existing 4.3.x database in place. See [Upgrade notes](#upgrade-notes).
- The contract-state change for untouched contracts adds a migration. TBD-L9[confirm the migration name and any GraphQL schema changes]

## Upgrade notes

:::caution[Re-index from genesis]
You must run a full re-index from genesis with 4.4.0. Wipe the indexer database and the ledger database, and re-index them together. Finish the re-index before the ledger 9 network upgrade, so your indexer is ready when Mainnet switches.
:::

- Moving from 4.3.800 to 4.4.x is not an upgrade path. The 4.3.x and 4.4.x lines can't share a database.
- If your database already indexes blocks past the upgrade with an earlier 4.4 build, re-index it so it serves the correct contract state after the switch.
- Sync from a local archive node if you can. It's much faster than a public RPC endpoint.
- Wallet SDK 2.x needs a 4.4.x indexer. Wallet SDK 1.x can't sync against Mainnet after the upgrade.
