* **Paired node**: 0.21
* **API version**: v3

---

## High-level summary

Midnight Indexer 3.1.0 adds support for Node 0.21, integrates the SPO indexer into the main repository, and changes how the indexer persists ledger state internally. It is the last minor release on the Indexer API v3 line before the 4.0.0 release moved to API v4 and Node 0.22.

---

## Audience

This release note is relevant for:

- Operators running the Midnight Indexer against Node 0.21
- Developers integrating against the Indexer API v3

---

## What changed

- Added support for Node 0.21 ([#761](https://github.com/midnightntwrk/midnight-indexer/pull/761))
- Integrated the SPO indexer into midnight-indexer ([#735](https://github.com/midnightntwrk/midnight-indexer/pull/735)) and switched docker-compose to the pre-built GHCR image, removing the unused NATS dependency ([#752](https://github.com/midnightntwrk/midnight-indexer/pull/752), [#754](https://github.com/midnightntwrk/midnight-indexer/pull/754))
- Used ledger storage for ledger state persistence ([#694](https://github.com/midnightntwrk/midnight-indexer/pull/694))
- Fetched genesis cNIGHT registrations from pallet storage in chain-indexer ([#733](https://github.com/midnightntwrk/midnight-indexer/pull/733))
- Included ledger parameters in the block query ([#745](https://github.com/midnightntwrk/midnight-indexer/pull/745))
- Updated the `debian:trixie-slim` base image to resolve CVE-2025-15467 ([#801](https://github.com/midnightntwrk/midnight-indexer/pull/801))

---

## New features

### Node 0.21 support

The indexer reads and applies blocks from Node 0.21. Operators upgrading their node to 0.21 need this release or later.

### SPO indexer

The SPO indexer that tracks stake pool operators moved into the midnight-indexer repository and ships from the same release. The docker-compose setup pulls its pre-built image.

### Ledger parameters on `Block`

The block query now exposes the ledger parameters in effect at that block.

---

## Breaking changes

None to the GraphQL API. The change to ledger state persistence is internal.

---

## Bug fixes

- The indexer API streams only the transactions relevant to active wallets ([#743](https://github.com/midnightntwrk/midnight-indexer/pull/743))
- Removed an `encode()` call on a varchar column in the `stakePoolOperators` query ([#753](https://github.com/midnightntwrk/midnight-indexer/pull/753))
