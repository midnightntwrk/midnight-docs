# Compact toolchain 0.36.1

- **Date:** 2026-11-11
- **Language version:** 0.28.0
- **Compact runtime version:** 0.21.0
- **Environment:** This release works with a Midnight ledger 9 blockchain.  For the full compatibility matrix, see the [release notes overview](https://docs.midnight.network/relnotes/overview)

## High-level summary

Version 0.36.1 of the Compact toolchain is a patch release.  It contains fixes for a pair of bugs in toolchain 0.36.0.

## Audience

These release notes are intended for Compact smart-contract developers and for DApp developers who use the Compact runtime.

## Fixed defect list

The following defects are fixed by updating to Compact toolchain 0.36.1.

- [Issue #616](https://github.com/LFDT-Minokawa/compact/issues/616): Certain circuits that used the `JubjubScalar` or `JubjubPoint` types would fail to generate prover and verifier keys due to a crash in the (separate) key-generation binary.  This was due to an upstream bug in the ZKIR implementation.  The issue is fixed upstream and this release contains a new key-generation binary containing the upstream fix.

- [Issue #856](https://github.com/LFDT-Minokawa/compact/issues/856): Certain circuits that used deserialized `Boolean` values would trigger an internal compiler error.  Toolchain 0.36.0 contained a partial fix for this issue but it was still possible to trigger the error.  This issue is now fixed in toolchain 0.36.1.
