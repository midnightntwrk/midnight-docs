## High-level summary

Midnight.js 5.0.2 is a maintenance patch. It changes no runtime code and no API. The packages carry the 5.0.1 code with refreshed dependencies, published from a new home: from this release, the packages are published to npm under the `@midnightntwrk` scope through OIDC trusted publishing, and the `@midnight-ntwrk` alias on GitHub Packages no longer receives new versions. Each GitHub release now carries its test evidence and the integrity hashes of the published packages.

The networks didn't change for this patch. They still run node 2.1.101, ledger 9.1.0.1, and indexer 4.4.101.

## Audience

This release note is relevant for developers who:

- Install Midnight.js or testkit-js packages from npm or GitHub Packages
- Run a DApp on Mainnet, Preview, or Preprod with Midnight.js 5.0.0 or 5.0.1

## Summary of updates

- Publishing moves to npm through OIDC trusted publishing under the `@midnightntwrk` scope. The `@midnight-ntwrk` alias to GitHub Packages is no longer published.
- Dependencies are refreshed from the green Dependabot pull requests. The ledger 9 stack stays at the 5.0.1 pins: `@midnightntwrk/ledger-v9` 1.0.2, `@midnightntwrk/onchain-runtime-v4` 4.0.2, Compact.js 3.0.2, and proof server 9.0.2.
- Each GitHub release now attaches its test evidence and a `published-packages` file listing the sha512 integrity of each published `@midnightntwrk` package, so you can compare it with `npm view <package>@<version> dist.integrity`.
- Documentation: the in-repo release notes for v5.0.1 and an API documentation update.

## Fixed issues

None. This patch changes no runtime code. The contract-call fixes for the ledger 9 networks are in [Midnight.js 5.0.1](/relnotes/midnight-js/midnight-js-5-0-1).

## Breaking changes

None. The API and the package names under the `@midnightntwrk` scope don't change. If you installed the `@midnight-ntwrk` alias from GitHub Packages, switch the install source to npm, as described in Upgrade.

## Upgrade

Move every `@midnightntwrk/midnight-js-*` package and `@midnightntwrk/testkit-js` to 5.0.2 together, installing from npm. The `@midnight-ntwrk` GitHub Packages alias stays at 5.0.1 and receives no 5.0.2 packages, so point your package manager at npm for the `@midnightntwrk` scope if it doesn't already resolve there. No code changes are needed, and you don't need to recompile or redeploy your contracts.

Run proof server 9.0.2 and Wallet SDK 2.0.1 with this release, unchanged from 5.0.1. For the full set of versions, see the [compatibility matrix](/relnotes/support-matrix).

## Known issues

- A trie insert in the ledger can produce a malformed trie that fails to deserialize. The full fix needs a hard fork. See [midnight-ledger#865](https://github.com/midnightntwrk/midnight-ledger/issues/865).
