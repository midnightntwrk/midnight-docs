# Environments and endpoints  

:::warning Preprod and Mainnet indexer and RPC moved to Blockfrost

The Midnight-hosted Mainnet endpoints `rpc.mainnet.midnight.network` and `indexer.mainnet.midnight.network` were retired at 22:00 UTC on 30 September 2026. As of 9 October 2026, the indexer hostname no longer resolves, and the RPC endpoint still answers requests but can stop at any time. [Blockfrost](https://blockfrost.io) is now the primary public provider of the Mainnet indexer and node RPC, and every request needs a Blockfrost **Midnight Mainnet** project token. To move an existing DApp, see [Migrating from the Midnight-hosted endpoints](../guides/networks-and-environments#migrating-from-the-midnight-hosted-mainnet-endpoints).

The Midnight-hosted Preprod endpoints `rpc.preprod.midnight.network` and `indexer.preprod.midnight.network` shut down from 22:00 UTC on 9 October 2026. Blockfrost now provides the Preprod indexer and node RPC too, and every request needs a Blockfrost **Midnight Preprod** project token. A Preprod token doesn't work on Mainnet, or the other way round.

The Preview endpoints stay the same.

:::

Midnight uses dedicated network services such as RPC nodes, indexer API, and proof server to power DApp development and interaction across the Preview, Preprod, and Mainnet environments. 
  
## Preview

The Preview environment is intended for early-stage development and experimentation.
Use these endpoints to connect your DApp to Midnight Preview environment. 

| Service | URL |
| --- | --- |
| Node RPC | `https://rpc.preview.midnight.network` |
| Indexer (GraphQL) | `https://indexer.preview.midnight.network/api/v4/graphql` |
| Faucet UI | https://midnight-tmnight-preview.nethermind.dev/ |
| Block explorers | https://preview.midnightexplorer.com/ |
|                 | https://midnight-preview.subscan.io/ |
|                 | https://explorer.1am.xyz/?network=preview      |

## Preprod

The Preprod environment is designed for final testing before mainnet deployment.
Use these endpoints to connect your DApp to Midnight Preprod environment. Blockfrost provides the public Preprod indexer and node RPC: create a **Midnight Preprod** project on [blockfrost.io](https://blockfrost.io) and append `?project_id=<token>` to each Node RPC and Indexer URL. See [Blockfrost: the Preprod and Mainnet indexer and RPC provider](../guides/networks-and-environments#blockfrost-the-mainnet-indexer-and-rpc-provider).

| Service | URL |
| --- | --- |
| Node RPC | `https://rpc.midnight-preprod.blockfrost.io` |
| Node RPC (WebSocket) | `wss://rpc.midnight-preprod.blockfrost.io` |
| Indexer (GraphQL) | `https://midnight-preprod.blockfrost.io/api/v0` |
| Indexer (WebSocket) | `wss://midnight-preprod.blockfrost.io/api/v0/ws` |
| Faucet UI | https://midnight-tmnight-preprod.nethermind.dev/ |
| Block explorers | https://preprod.midnightexplorer.com/ |
|                 | https://midnight-preprod.subscan.io/  |
|                 | https://explorer.1am.xyz/?network=preprod      |

## Mainnet

The Mainnet environment is the production network.
Use these endpoints to connect your DApp to Midnight Mainnet. The public Mainnet indexer and node RPC are provided by Blockfrost: create a **Midnight Mainnet** project on [blockfrost.io](https://blockfrost.io) and append `?project_id=<token>` to each Node RPC and Indexer URL. See [Blockfrost: the Preprod and Mainnet indexer and RPC provider](../guides/networks-and-environments#blockfrost-the-mainnet-indexer-and-rpc-provider).

| Service | URL |
| --- | --- |
| Node RPC | `https://rpc.midnight-mainnet.blockfrost.io` |
| Node RPC (WebSocket) | `wss://rpc.midnight-mainnet.blockfrost.io` |
| Indexer (GraphQL) | `https://midnight-mainnet.blockfrost.io/api/v0` |
| Indexer (WebSocket) | `wss://midnight-mainnet.blockfrost.io/api/v0/ws` |
| Block explorers | https://midnightexplorer.com/ |
|                 | https://midnight.subscan.io/  |
|                 | https://explorer.1am.xyz      |
| cNgD DApp | https://midnight-dust-mainnet.nethermind.io/ |
