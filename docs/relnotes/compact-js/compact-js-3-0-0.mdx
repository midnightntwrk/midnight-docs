## High-level summary

Compact.js 3.0.0 is the major release for the [ledger 9 network upgrade](/relnotes/ledger-9). Midnight.js 5 uses it to run contracts on Mainnet after the upgrade.

Preview and Preprod stay on ledger 8 until a later upgrade. For those networks, keep using Compact.js 2.5.x with Midnight.js 4.1.1.

---

## Audience

This release is relevant for developers who:

- Move a DApp to Midnight.js 5 for Mainnet
- Use `@midnight-ntwrk/compact-js` or `@midnight-ntwrk/compact-js-command` directly

## Breaking changes

- Built against Compact runtime 0.21.0, the runtime for ledger 9.
- Requires Compact toolchain 0.36.0, the toolchain for ledger 9.
- Type surfaces are aware of the ledger era. Code that assumed a single ledger era must select the era explicitly. Rebuild against the new API surface.
