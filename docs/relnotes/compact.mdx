# Compact toolchain

Compact is Midnight's smart contract programming language, designed for building secure, efficient, and adaptable decentralized applications.

The Compact toolchain includes the Compact compiler, formatter, and the Compact "fixup" tool.
The compiler translates Compact smart contract code into JavaScript implementations and a representation of the zero-knowledge circuits.

[Link to related documentation](../compact/compilation-and-tooling/compiler-usage)

To install the toolchain, first install the [Compact devtools](compact-tools.mdx). Then install the toolchain for the network you deploy to, as listed in the [compatibility matrix](support-matrix.mdx):

- **Mainnet** runs ledger 9 after the [ledger 9 network upgrade](ledger-9.mdx) and uses toolchain TBD-L9[Compact toolchain 0.35.0 or 0.36.0].
- **Preview and Preprod** run ledger 8 until their upgrade. Run `compact update 0.31` to get toolchain 0.31.x for these networks.

A bare `compact update` installs the newest release, which can target a ledger version that your network does not run yet.
