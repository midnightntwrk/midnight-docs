# Onchain Runtime

:::info[On-chain runtime releases are now part of Ledger]
Starting with Ledger 7.0.0, on-chain runtime versions appear on the [Ledger page](./ledger), not on this page. The on-chain runtime keeps its own version number. For example, Ledger 8.1.2 includes on-chain runtime 3.1.1. For other releases, see [Component versions by release](./ledger#component-versions-by-release). To choose the version for a DApp, see the [compatibility matrix](./support-matrix).

Release 4.0.0 on this page takes its number from Ledger 4.0.0, released on 12 May 2025. The on-chain runtime package in that release is `@midnight-ntwrk/onchain-runtime` 0.3.0, so it predates on-chain runtime 2.0.0 and every later version.
:::

Onchain Runtime is a component of the Midnight infrastructure that enables zero-knowledge proof generation, transaction verification, and privacy-preserving transaction processing.

[Link to related documentation](/api-reference/onchain-runtime/)

To download the component, click the appropriate link under **Artifacts**.
