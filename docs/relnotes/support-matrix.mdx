# Compatibility matrix

---

This compatibility matrix, also called the support matrix, lists the Midnight component versions tested against [Preview](#preview-support-matrix), [Preprod](#preprod-support-matrix), and [Mainnet](#mainnet-support-matrix). For releases that don't work with these versions, see [Known incompatible combinations](#known-incompatible-combinations).

:::note
This matrix only reflects the latest tested versions. Earlier versions may still work, but we do not guarantee compatibility or provide support for them.
:::

## Known incompatible combinations

Preview, Preprod, and Mainnet run ledger 8. Compact toolchains 0.34.0 and 0.35.0 target ledger 9, and so do Compact runtimes 0.19.0 and 0.20.0. They don't work with the versions in this matrix.

| Combination | Result |
|-------------|--------|
| Compact runtime 0.19.0 or 0.20.0 with Midnight.js 4.1.1 | Midnight.js 4.1.1 pins `@midnight-ntwrk/compact-runtime` to 0.16.0 and `@midnight-ntwrk/onchain-runtime-v3` to 3.0.0. Compact runtime 0.19.0 and 0.20.0 depend on `@midnightntwrk/onchain-runtime-v4` instead. Even when the toolchain matches the runtime, `deployContract` throws `Failed to configure constructor context with coin public key`. The coin public key isn't the cause: Midnight.js 4.1.1 doesn't support contracts compiled for ledger 9. |
| Compact toolchain 0.34.0 or 0.35.0 with Compact runtime 0.16.0 | Importing the compiled contract throws `Version mismatch: compiled code expects 0.19.0, runtime is 0.16.0`. For toolchain 0.35.0, the expected version is 0.20.0. |
| Compact toolchain 0.31.1 with Compact runtime 0.19.0 or 0.20.0 | Importing the compiled contract throws `Version mismatch: compiled code expects 0.16.0, runtime is 0.20.0`. For Compact runtime 0.19.0, the message ends with `runtime is 0.19.0`. |
| Contracts compiled with Compact toolchain 0.34.0 or 0.35.0, deployed to Preview, Preprod, or Mainnet | These toolchains compile for ledger 9. Ledger 8 can't read the initial contract state of these contracts, so you can't deploy them to these networks. |

A bare `compact update` installs the newest toolchain and makes it the default. In a project that doesn't list the Compact runtime yet, `npm install @midnight-ntwrk/compact-runtime` without a version adds the newest runtime. To stay on the versions in this matrix, run `compact update <version>` and `npm install @midnight-ntwrk/compact-runtime@<version>`.
