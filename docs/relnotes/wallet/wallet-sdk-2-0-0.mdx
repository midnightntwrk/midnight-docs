## High-level summary

Wallet SDK 2.0.0 is the major release for the [ledger 9 network upgrade](/relnotes/ledger-9). Wallet SDK 1.x can't sync or transact on Mainnet after the upgrade, so every Mainnet wallet and DApp needs 2.0.0 and a 4.4.x indexer.

Wallet SDK 2 runs ledger 8 before the upgrade and ledger 9 from it, so balances, coins, and history carry across the switch. Preview and Preprod stay on ledger 8 until a later upgrade. For those networks, keep using wallet SDK 1.2.0.

## What changed (Summary of updates)

- Detects the switch to ledger 9 when the chain reports `protocolVersion` 2000000 or higher. `FacadeState.protocol` moves from `Crossing` to `Settled`.
- Tags each transaction with its protocol version and refuses a mismatch with `ProtocolVersionMismatchError`.
- Fails a transaction if the chain changes version while it proves the transaction, and releases the coins it reserved.
- Adds configuration for the upgrade schedule, per-ledger provers, and a chain version probe. TBD-L9[final configuration field names]

### DUST after the upgrade

TBD-L9[approved DUST wording: replace or confirm this paragraph]

DUST state resets at the ledger 9 network upgrade. On Mainnet, DUST generation backed by cNIGHT is replayed automatically to the full cap, so cNIGHT holders don't need to register again. NIGHT bridged to Midnight after the upgrade needs a first-time registration with `registerNightUtxosForDustGeneration`. TBD-L9[bridge enabled at fork?] For about 3 minutes after the switch, the network accepts no user transactions while DUST is rebuilt. Wallets show the replayed DUST only on wallet SDK 2 with a synced 4.4.x indexer.
